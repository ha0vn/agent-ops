# Agent Ops — Implementation Plan (v1: Claude Code + khung đa nguồn)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Một web app chạy trên máy (localhost) đọc log Claude Code, hiển thị 6 màn hình của spec với dữ liệu trực tiếp, đóng gói thành plugin `/agent-ops` + chạy tay bằng `node`, sẵn khung bộ chuyển đổi cho các công cụ AI khác.

**Architecture:** Node thuần (không framework, không phụ thuộc runtime). `src/sources/*` đọc dữ liệu từng công cụ thành mô hình `Session → Agent → Event` chung; `src/store.js` giữ trạng thái trong bộ nhớ, đọc tăng dần, lưu tóm tắt lịch sử; `src/server.js` phục vụ `web/` tĩnh + `/api/*` + SSE `/events`. Giao diện là các trang HTML/CSS/JS từ mockup v2, đổi `window.AO_DATA` tĩnh thành dữ liệu tải từ API và vẽ lại khi có sự kiện.

**Tech Stack:** Node.js ≥ 20 (ES modules, `node:test`, `node:http`, `fs.watch`), HTML/CSS/JS thuần, Claude Code plugin manifest.

**Spec:** `docs/superpowers/specs/2026-11-26-agent-ops-design.md` (tiếng Việt). Mockup đã duyệt: `docs/mockups/` — `build-data.js` trong đó là **bản tham chiếu đã chạy đúng trên dữ liệu thật** cho mọi phép tính ở mục 7 của spec; các task bên dưới chuyển nó thành module có test, không phát minh lại.

**Phạm vi:** plan này làm nguồn **Claude Code** đầy đủ + khung đa nguồn (registry, cờ năng lực, nhãn/bộ lọc nguồn). Bộ chuyển đổi Codex / Gemini CLI / Cursor / Copilot / Antigravity là các plan riêng, mỗi plan bắt đầu khi có **phiên mẫu thật** (spec §5b).

## Review Focus

1. **Dòng đang ghi dở** (Claude Code ghi nửa dòng JSON lúc ta đọc) → không được đếm là dòng hỏng, phần dở giữ lại ghép với lần đọc sau. Test: Task 3 `reader keeps partial trailing line`.
2. **Log lớn / phiên khổng lồ** (máy thật ~1GB, phiên 71 agent) → khởi động < 10 s, làm mới tăng dần chỉ đọc phần mới. Test: Task 5 `refresh reads only appended bytes` + `50k-line session builds under 2s`.
3. **Định dạng log trôi** (kiểu bản ghi lạ, thiếu `usage`, model `<synthetic>`, dòng hỏng) → bỏ qua, đếm `badLines`, không sập. Test: Task 3 `tolerates unknown records and bad lines`.
4. **Rò dữ liệu nhạy cảm** qua API → `/api/data` không chứa email/token. Test: Task 7 `api data is redacted`.
5. **Chạy lần hai / cổng bận** → lệnh thứ hai dùng lại server đang chạy (mở trình duyệt tới nó) thay vì báo lỗi; cổng bận bởi app khác → cổng kế. Test: Task 12 `second launch reuses running instance` + `busy port falls through`.
